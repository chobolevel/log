# 설계 문서

기능 단위 설계 문서를 둔다. PR에서 이 문서를 링크해 리뷰 기준으로 사용한다.

- 파일명은 `<기능-slug>.md`로 한다.
- 한 문서에 슬라이스 분해(동작 변화 단위), 슬라이스별 테스트 케이스, 위험도를 포함한다.
- 구조 수준의 결정(모듈, 패키지, 인프라 선택 등)은 `decisions/`에 ADR로 남긴다.
- 작성 템플릿은 `/design` command로 고정할 예정이다. 그 전까지는 아래 항목을 따른다.

## 기본 항목

배경과 목표 / 결정 사항(대안과 선택 이유) / 슬라이스 / 슬라이스별 테스트 케이스 / 위험도와 리뷰 깊이 / 비범위 / 열린 질문
